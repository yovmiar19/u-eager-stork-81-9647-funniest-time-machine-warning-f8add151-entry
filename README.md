Entry for the [make.fun bounty "Funniest Time Machine Warning Label"](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151).

The program writes a single warning label for a time machine — 80 characters, well inside the 120-character cap — to `/output/entry.txt`. The label is validated in `main.ts` before it is written, so the output is always 1–120 characters.

> WARNING: If you run into your past self, do not apologize. He knows what he did.

## Run

```sh
node main.ts
```

It writes the label to `/output/entry.txt` and prints the character count.
