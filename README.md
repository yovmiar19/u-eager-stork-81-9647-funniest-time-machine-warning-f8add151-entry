[![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151)

[![Node.js](https://img.shields.io/badge/node-%3E%3D22-brightgreen)](https://nodejs.org/)

Entry for the make.fun bounty **Funniest Time Machine Warning Label**.

The program writes a single warning label for a time machine — 80
characters, well inside the 120-character cap — to `/output/entry.txt`:

> WARNING: If you run into your past self, do not apologize. He knows what he did.

## Run

```sh
node main.ts
```

It writes the label to `/output/entry.txt` and prints the character count.
